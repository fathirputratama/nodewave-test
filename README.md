# Todo List App

Aplikasi web todo list menggunakan Next.js, Zod, Tanstack Query, dan Shadcn UI.

## Cara menjalankan
1. Clone repository:
   ```bash
   git clone https://github.com/fathirputratama/nodewave-test.git
   cd nodewave-test
   ```
2. Install dependensi:
   ```bash
   npm install
   ```
3. Jalankan server:
   ```bash
   npm run dev
   ```
4. Akses:
   ```bash
   Halaman registrasi: http://localhost:3000/auth/register
   Halaman login: http://localhost:3000/auth/login
   ```
